To use it:

1. In the notebook’s global params cell, keep your benchmark inputs stable. In practice that means using a fixed container image tag instead of master-latest, keeping the same PHOLD settings, and keeping the same num_comps_per_trial values for every regression run.
2. For the first known-good run, set regression_mode to generate-baseline.
3. Run the notebook through Preprocess so it produces runs/results.csv.
4. Run the new Regression testing cell. That will copy the current CSV to regression_baseline_csv.
5. Preserve that baseline file with the workflow so future runs compare against the same reference.
6. For later regression runs, change regression_mode to compare and run the notebook again through Preprocess.
7. Run the Regression testing cell. It will fail with an AssertionError if any selected metric drifts outside tolerance or if the set of tested sizes changes.

The main knobs are already in the notebook: regression_baseline_csv, regression_metrics, regression_relative_tolerance, and regression_absolute_tolerance.
